## Figures

The `figures` folder contains visualizations generated from the Emotion-Behavior BERT model and the dataset.

- `emotion_distribution.png` : Shows the distribution of emotion labels in the dataset.
- `behavior_distribution.png` : Shows the distribution of behavior labels in the dataset.
- `predicted_emotion_percentages.png` : Shows predicted emotion percentages for a sample summary.
- `predicted_behavior_percentages.png` : Shows predicted behavior percentages for a sample summary.
