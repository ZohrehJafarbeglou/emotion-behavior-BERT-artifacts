# Emotion-Behavior BERT Artifacts

This repository contains all artifacts (data, code, and figures) related to the Emotion-Behavior BERT study.

## Data
The `data` folder contains the Excel datasets used for training and testing the BERT model.

- `LAST_merged_file_with_BSI.xlsx` – Main dataset with emotion and behavior labels.
- `LAST_merged_file_with_main dataset.xlsx` – Additional dataset for testing or validation.

## Code
The `code` folder contains Python scripts for preprocessing, training, and evaluating the BERT emotion-behavior model.

- `NEW_AMOZESH.py` – Complete training, evaluation, and prediction pipeline using PyTorch and Transformers.

## Figures
The `figures` folder contains visualizations generated from the model and dataset.

- `Drawing2.pdf` – Schematic representation of the overall workflow and methodology.
- `mafhoumi.png` – Conceptual illustration of emotion-behavior mapping.
- `model 1.png` – Visualization of the BERT model architecture used for classification.
- `model.png` – Example outputs showing emotion and behavior predictions on sample data.
